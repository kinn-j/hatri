OPTIONAL: package public dish photos (no Claude dependency)

1. Copy JPG, PNG, or WEBP images into this images/ folder.
2. Edit photos.json to map a lowercase hyphenated recipe name to the image file name.
   Example:
   {
     "dal-tadka": "Dal Tadka.jpg",
     "aloo-gobi": "Aloo Gobi.jpg",
     "paneer-bhurji": "Paneer Bhurji.webp"
   }
3. Upload your entire updated website folder again.
4. Use photos you own or have permission to republish.

Images saved inside the original Claude Artifact are NOT embedded in the
exported HTML and must be obtained/exported separately. Without the extra
photos, Raman Rasoi will still show its built-in emoji dish illustrations.
